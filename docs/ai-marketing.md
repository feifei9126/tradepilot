# AI 营销：新手使用与配置说明

页面入口：侧栏 **增长 → AI 营销**（`/app/leads`）。这里根据你填写的活动、目标市场和产品资料，生成一份可编辑的营销文案/跟进计划草稿。它不是邮件群发器或广告投放器。

## 第一次使用：配置工作区自己的文本模型

普通 SaaS 工作区：

1. 请**工作区所有者或管理员**打开侧栏「AI 用量」（`/app/ai-usage`）。普通成员不用也不能修改密钥，配置好后即可生成草稿。
2. 选择你已有账号和 API 额度的服务商，填写该服务商签发的 **API Key** 和模型 ID。API Key 不是 ChatGPT 登录密码或会员订阅。服务地址使用官方预设，不需要也不允许自行填写任意 URL。
3. 设置每月请求/Token 预算，勾选「允许本工作区调用 AI」，点击保存。Key 加密存入 PostgreSQL，只显示已保存、不回显；留空不更换 Key，切换服务商须填写新 Key。
4. 查看页面的「有效上限」：实际额度是**套餐权益、平台上限、工作区预算的最低值**，填写更高预算不会升级套餐。订阅失效会回到免费套餐，工作区/AI/计费停用会拒绝调用。失败/超时请求也保守计入预算，不代表供应商没有收费。
5. 回到 AI 营销生成一份小草稿。生成会实际请求服务商，可能计费；失败时检查页面提示、服务商模型权限/余额和「AI 用量」记录。

仅**平台管理员的实例操作**仍走「系统 → API 配置中心」：保存实例文本模型、第 2 步「AI 营销文案」模型覆盖可留空、第 4 步测试连接。普通租户不会借用平台共享 Key 或其他工作区配置。页面配置按钮会按当前身份指向正确入口。

模型平台的账号、额度、模型权限和 API 计费由你与平台确认。只在可信实例配置密钥，不要将密钥写入活动名称、产品资料或素材 URL；Token 上限不是货币账单。

## 页面操作：三步完成一份草稿

1. **活动配置**：给活动起一个名字，勾选需要的文案类型（邮件、WhatsApp、社媒广告方案），填写目标行业和国家。计划日期是写在方案里的建议日期，不会触发定时任务。
2. **产品与素材**：从产品库选择要推广的产品；也可以添加图片/视频公开 URL。优先提供准确且可公开访问的资料。不要放客户隐私、内部文档、密码或签名链接。
3. 点击 **整理文案与跟进计划草稿**。右侧出现结果后，逐句检查。特别核实产品参数、价格、认证、库存、交期和所有承诺；不准确时直接编辑或重新补充资料再生成。
4. 需要保留时点击保存。当前草稿只保存在**这台设备、这个浏览器的本地存储**，清理浏览器数据可能会删除，不能自动与同事或其他设备同步。

## 目前不会替你做的事

- 不会发送邮件、WhatsApp 或社媒消息，也不连接收件箱。
- 不会登录社媒、发布内容、创建/管理广告或向 LinkedIn/Facebook/Google Ads 提交投放。
- 社媒预算和计划日期只作为模型生成方案时的参考文字，不会扣费或排期。
- 不会验证联系人是否同意接收营销内容。向外发送前须核实对象、事实、许可及当地营销/隐私规则。系统 SMTP 的通用发送入口按营销邮件处理，要求收件人在确认邮件中完成订阅确认；不能用 `marketing:false` 或管理员代填同意绕过。

模型调用会把本页活动名称、渠道、目标市场、已选择的产品名称和素材链接等内容发送至当前工作区（平台管理员则为实例）配置的模型服务；请先确认该服务符合你对数据的要求。生成结果是模型建议，可能不准确，也可能产生 API 费用。

## 常见问题

- **点生成提示先配置模型**：普通租户请管理员检查「AI 用量」的 Key、启用开关和有效预算；平台管理员检查 API 配置中心。页面不会回退共享 Key。刷新后重试。
- **API Key 无效/额度不足/模型不可用**：在模型服务商控制台核对 Key、账号余额、区域和模型权限；模型名称须与服务商提供的 ID 匹配。
- **提示有效额度不足**：检查「订阅计费」是否有效，以及工作区预算、平台上限和本月消耗；失败预留也计入额度。降低输出长度或由管理员处理，不能仅把预算调高绕过套餐。
- **平台管理员的模型覆盖仍失败**：API 配置中心第 2 步仍使用默认服务商的地址和 Key，不同平台模型 ID 不能混用。
- **保存后换设备看不到草稿**：这是预期行为；现阶段营销草稿只存在当前浏览器，并非服务端团队共享记录。
- **想自动搜索潜在客户**：请使用旁边的 **AI 获客**。自动搜索需要另行配置 Firecrawl，文本模型不能代替 Firecrawl。
