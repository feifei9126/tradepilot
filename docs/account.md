# 个人中心

登录后从右上角头像或侧边栏「个人中心」进入 `/app/account`：

- 查看只读登录邮箱，修改显示名称、界面语言和个人时区。
- 使用当前密码修改登录密码；普通用户及开发模式为 8–128 位，**production 部署管理员**为 16–128 位、至少两类字符且不能使用公开示例/明显弱密码。成功后当前浏览器退出登录。
- 部署管理员的设置写入 `TRADEPILOT_DATA_DIR/admin-account.json`（Docker 数据卷，文件权限 0600）；密码仅保存 PBKDF2-SHA256 哈希。修改后该哈希优先于 `TRADEPILOT_ADMIN_PASSWORD` 环境变量，重启容器仍有效。环境变量不会被网页写回。
- 数据库注册用户使用其 `users.name` 与 `users.settings`，保留已有其他设置字段。

目前时区仅作为个人偏好保存，尚未统一作用于各业务列表的时间格式。修改密码会轮换会话版本，所有旧会话在下次访问时失效；角色变更、停用和密码重置也会撤销旧会话。临时密码用户首次登录只可进入个人中心改密，随后重新登录。若管理员忘记修改后的密码，需要有服务器数据卷管理权限的部署人员处理，不要通过公开接口重置。


团队添加成员、一次性临时密码与权限见 [SaaS 多用户指南](saas-multi-user.md)。`db:init --reset-password` 仅重置明确初始化的数据库账号，不会修改本地部署管理员文件；正常启动不会覆盖个人设置、密码或停用状态。

## 生产管理员与升级注意事项

- 安装器为新安装随机生成初始密码；生产启动和认证会拒绝弱初始密码，首次登录必须改密，再重新登录。
- 正常升级不覆盖已保存密码哈希、偏好、角色或停用状态。`TRADEPILOT_ADMIN_PASSWORD` 不是已改密账号的后门；管理员文件损坏时拒绝回退到环境密码。
- 若旧部署管理员仍使用弱密码，先在受控旧实例的个人中心改为强密码，并备份数据卷与密钥，再升级。不得删除 `admin-account.json` 来临时放开认证。需恢复账号时按有审计的运维流程处理，不能启用公开重置接口。
- 登录节流跨副本存入 PostgreSQL；未配置可信代理时，所有未验证来源共用 IP 桶。代理设置见[生产运维手册](production-operations.md)。不要通过清库或反复重启绕过登录限制。

本轮源码整改没有更改现有本地预览密码或重启预览容器；生产强密码策略仅在升级到新代码后生效。
