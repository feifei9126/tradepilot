# TradePilot「远航增长工作台」界面设计

本次按用户提供的 Prisma 创意工作室参考重新设计。保留深色电影感、暖米白文字、超大品牌字标和克制动效，重写为外贸团队可以理解和操作的产品语言。继续使用现有 Next.js、React、TypeScript、Tailwind CSS 4、motion/react 与 lucide-react，不迁移 Vite 或另起项目。

## 贴合 TradePilot 的提示词

为 TradePilot 设计官网、认证入口及统一业务后台。面向小型外贸团队，覆盖 AI 获客、AI 营销、客户/询盘、报价/订单和产品内容。视觉主题是远航、港口与贸易连接，而不是艺术家作品集。

官网包含三个主要章节：Hero、业务路径、核心工作流。Hero 用低饱和港口摄影、墨绿黑背景、暖米白 TradePilot 大字标与清晰的中文价值主张。导航可直接跳到章节、登录或注册。业务路径准确呈现「公开网页发现 → 人工确认营销草稿 → 进入 CRM → 报价履约」；功能入口指向真实已有路由。内容明确 BYOK 和人工确认边界，不编造客户数量、转化率、付费案例或尚不存在的自动群发能力。

后台以暖中性的明亮工作画布配墨绿导航，保持表格和表单阅读密度。统一字号、圆角、边线、按钮与焦点样式；将平台管理和租户业务视觉区分，仍严格使用现有角色权限。AI 获客与营销的说明折叠成可展开指南，核心操作与服务配置保持可见。不得把官网的大字体、颗粒滤镜或重动效带入业务数据区。

字体使用现有 Inter 与系统中文字体；英文强调使用衬线斜体，中文标题保持可读性。品牌配色为墨绿黑 #101a16、奶油白 #e4e1d2、柔和黄铜 #c3aa77、深绿操作色 #28624b。动画仅用于首次进入、导航反馈与交互状态；尊重 prefers-reduced-motion，正文不能依赖动画加载才显示。

桌面、平板和手机都应可用；导航、对话框、折叠指南保持键盘可达，图标按钮有名称，表单标签和错误信息保留。照片保存到本地 public/images，避免外部视频依赖、自动播放耗流量或闪烁。完成后在浏览器验证真实登录、SaaS 角色限制、获客/营销页面、移动布局和横向溢出。
