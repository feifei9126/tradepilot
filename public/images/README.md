# TradePilot website imagery

`trade-harbor.jpg` is the verified 1600×1067 harbor photograph used by the public website and authentication panels. It is saved locally so page rendering does not depend on an external video player or image CDN.

Source: `https://images.unsplash.com/photo-1578575437130-527eed3abbec` (Unsplash). Reference licensing: `https://unsplash.com/license`.

The design does not use the Prisma reference's creative-studio videos or icon images. Screenshot previews and QA artifacts are stored outside the repository, and no business data is embedded in website illustrations.
